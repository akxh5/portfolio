# Personal Portfolio

A modern, responsive personal portfolio built with React 19, Vite, TailwindCSS, Framer Motion, and GSAP.

## Features

- ⚡️ Powered by Vite & React 19
- 🎨 Styled with Tailwind CSS & Radix UI
- ✨ Smooth animations using Framer Motion & GSAP
- 📊 GitHub contribution graph integration

## Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) or [Bun](https://bun.sh/) installed.

### Installation

```bash
npm install
# or
bun install
```

### Running Locally

```bash
npm run dev
# or
bun dev
```

### Build

```bash
npm run build
```
